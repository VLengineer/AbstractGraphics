# Psychedelic Fractal Explorer

Интерактивная визуальная песочница с элементами аркады, где игрок "летит" через процедурно генерируемое психоделическое пространство.

## 🚀 Установка

```bash
# Перейдите в директорию проекта
cd psychedelic_explorer

# Установите зависимости
pip install -r requirements.txt
```

Или вручную:

```bash
pip install pygame moderngl numpy
```

## 🎮 Запуск

```bash
cd /workspace
python -m psychedelic_explorer.main
```

Или напрямую:

```bash
python /workspace/psychedelic_explorer/main.py
```

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| **WASD** | Движение камеры |
| **Мышь** | Направление взгляда |
| **Space** | Вспышка (тратит энергию) |
| **Shift** | Ускорение времени |
| **Esc** | Пауза |
| **R** | Рестарт (в GAMEOVER) |
| **1-4** | Смена палитры |
| **F** | Fullscreen toggle |
| **Tab** | Смена мира вручную |
| **Enter/Space** | Старт игры (в меню) |

## 🌍 Типы миров

1. **Fractal World** — Анимированное множество Жюлиа с морфингом
2. **Tunnel World** — Бесконечный фрактальный туннель
3. **SDF World** — Реймарчинг странных 3D-форм

Миры автоматически меняются каждые 30 секунд или вручную (Tab).

## 🎲 Случайные события

Каждые 15-45 секунд происходит одно из событий:

- `palette_shift` — плавная смена цветовой палитры
- `fractal_morph` — морфинг между типами фракталов
- `gravity_flip` — инверсия управления (5-10 сек)
- `time_warp` — замедление/ускорение времени
- `color_invert` — инверсия цветов (2-5 сек)
- `sdf_mutation` — случайная комбинация SDF-примитивов
- `zoom_pulse` — пульсация масштаба

## 🎨 Особенности

- **GPU рендеринг** через ModernGL (шейдеры GLSL 330)
- **Пост-процессинг**: bloom, trails, хроматическая аберрация
- **Процедурная генерация**: палитры, параметры фракталов, SDF-комбинации
- **FSM система состояний**: Menu → Play → Pause → GameOver
- **Система объектов**: Energy orbs (+очки), Hostile forms (-здоровье), Portals (телепорт)
